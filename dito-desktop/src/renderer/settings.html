Início

Aperte a tecla, fale, e o texto aparece onde o cursor estiver.

Como usar

Clique onde você quer o texto — terminal, navegador, qualquer campo de escrita.
Aperte F9 e fale.
Aperte F9 de novo. O texto é digitado ali, com pontuação.

Atalho

A tecla funciona em qualquer janela, mesmo com o Dito fechado na bandeja.

A tecla é capturada só pelo Dito — ela não chega ao programa embaixo.

Áudio

De onde o Dito ouve, e o que ele faz com o texto pronto.

Evite entradas com “monitor” ou “mixagem estéreo” no nome: elas gravam o som que sai do computador, não a sua voz.
Desligado, o texto só vai para o histórico.

Modelos

O modelo padrão vem junto. Os outros você baixa só se quiser.

Para não deixar você sem transcrição, só é possível apagar um modelo quando existe outro instalado.
